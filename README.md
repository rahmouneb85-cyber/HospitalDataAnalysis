# Hospital Data Analysis

Mini-project to manipulate patient data and visualize basic statistics.

## Project structure
- `data/patients.csv` : patient dataset (PatientID, Age, Sex, BloodPressure, Cholesterol, Diagnosis)
- `notebooks/patients_analysis.ipynb` : data exploration and visualization
- `scripts/` : optional Python scripts

## Setup
```
conda create -p ./env python=3.11
conda activate ./env
pip install -r requirements.txt
jupyter notebook
```
